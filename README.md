## 어떤 문제였나

금융·검색·쇼핑·날씨·요일 정보를 이용해 두 지수가 D+3에 상승할 확률을 각각 제출하는 과제입니다. 각 타깃의 ROC-AUC와 두 AUC의 평균을 확인했습니다. 과제 전체 평가는 정량 60점과 정성 40점으로 구성되어 있었습니다.

| 데이터 | 규모 |
|---|---|
| 학습 | 924행 · 입력 변수 284개 |
| Public | 100행 |
| Private | 200행 |
| 입력 그룹 | 금융 18 · 검색 51 · 쇼핑 199 · 날씨 15 · 요일 1 |

Public 100행과 Private 앞 100행은 동일한 관측 구간입니다. 두 파일을 별개의 독립 평가 표본으로 취급하지 않았습니다.

## 점수를 올리는 데 사용한 접근

**타깃별 모델링.** 건강식품에서는 강한 요일 패턴을 발견했고, 금융에서는 원값보다 최근 변화량과 변수 간 차이를 살펴봤습니다. 같은 모델과 같은 특성을 두 타깃에 일괄 적용하는 방식에서 벗어났습니다.

**과거로 학습하고 이후를 검증.** 시간순 분할을 사용하고, D+3 라벨 경계를 고려해 학습과 검증 사이에 3행을 비웠습니다. 스케일러와 모델은 각 학습 구간에서만 적합했습니다.

**요일별 수요와 금융 보조 예측.** 건강식품은 과거 같은 요일의 수요로 앞으로의 수요를 추정했습니다. 금융은 변화량을 먼저 예측하는 보조 모델과 NCA·KNN 조합도 비교했습니다.

**제출까지 재현.** 고정 설정, 예상 예측, 실험 결과를 남기고 CSV 행 순서와 확률 범위, 재학습 결과를 점검했습니다.

요일 인덱스의 실제 월~일 매핑은 확인되지 않았습니다. 위 그림은 학습 구간의 관측 패턴입니다.

## 실행

Python 3.12 환경을 사용합니다. 제공받은 원본 데이터 5개를 `src/data/`에 준비한 뒤 실행합니다. 데이터는 저장소에 포함하지 않았습니다.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd src
python -m unittest test_clean_causal test_clean_causal96_stage2
python train_selected.py
python predict_submission.py --model-dir models_retrained
```

**코드의 재현 대상은 과거 stage2 후보입니다.** 이 후보의 로컬 Public 평균은 공식 4회차와 같은 `0.832397`이며, 최종 1등 결과 `0.856276`을 만든 정확한 제출 파일·설정과의 연결은 현재 기록만으로 확인되지 않았습니다. 따라서 포함한 코드를 최종 우승 모델이라고 소개하지 않습니다. 재학습한 예측은 `src/expected/`의 해당 과거 후보와 비교합니다.
